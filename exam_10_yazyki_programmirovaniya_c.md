# ГЭ 10. Языки программирования и программирование на C

Файл подготовлен как отдельный экзаменационный конспект по этапам решения задач на ЭВМ, алгоритмам, жизненному циклу программы, модульному программированию и языку C.

---

## 1. Этапы решения задач на ЭВМ

Типовые этапы:

1. Постановка задачи.
2. Анализ предметной области.
3. Формализация задачи.
4. Выбор метода решения.
5. Разработка алгоритма.
6. Выбор структур данных.
7. Запись программы на языке программирования.
8. Трансляция программы.
9. Тестирование и отладка.
10. Анализ результатов.
11. Документирование.
12. Сопровождение.

Постановка задачи должна содержать входные данные, выходные данные, ограничения и требования к результату.

## 2. Алгоритмы: способы записи и требования

Алгоритм - точное описание последовательности действий, приводящих к решению задачи за конечное число шагов.

Свойства алгоритма:

- определенность;
- дискретность;
- конечность;
- результативность;
- массовость.

Способы записи:

- естественный язык;
- псевдокод;
- блок-схема;
- таблица решений;
- программа на языке программирования.

Базовые структуры алгоритмов:

- следование;
- ветвление;
- цикл.

## 3. Жизненный цикл программы

Жизненный цикл программы включает:

- анализ требований;
- проектирование;
- кодирование;
- тестирование;
- внедрение;
- эксплуатацию;
- сопровождение;
- модернизацию.

Спецификация программы - описание того, что должна делать программа, какие данные принимает, какие результаты выдает и каким ограничениям должна удовлетворять.

---

## 4. Анализ, конструирование и верификация программ

Анализ программ включает:

- проверку корректности;
- оценку сложности;
- поиск ошибок;
- анализ использования памяти;
- проверку соответствия требованиям.

Конструирование программ - процесс построения программы из алгоритмов, структур данных, модулей и интерфейсов.

Верификация - доказательство или проверка того, что программа соответствует спецификации.

Методы верификации:

- тестирование;
- инспекция кода;
- формальные доказательства;
- статический анализ;
- проверка инвариантов.

## 5. Интегрированные среды разработки

Интегрированная среда разработки предоставляет инструменты для создания программ.

Обычно включает:

- редактор кода;
- компилятор или интерпретатор;
- отладчик;
- систему подсказок;
- управление проектом;
- средства сборки;

## 6. Основные понятия языков программирования

Машинный язык - язык команд, непосредственно исполняемых процессором.

Алгоритмический язык - язык высокого уровня, предназначенный для записи алгоритмов в форме, удобной человеку.

Исходный текст проходит стадии:

1. Препроцессорная обработка.
2. Компиляция.
3. Компоновка.
4. Загрузка.
5. Выполнение.

Для интерпретируемых языков часть стадий может выполняться иначе.

Метаобозначения используются для формального описания синтаксиса языка.

## 7. Данные и системы счисления

Данные - представление информации в форме, пригодной для обработки программой.

Типы данных:

- целые;
- вещественные;
- символьные;
- логические;
- массивы;
- записи или структуры;
- указатели;
- строки;
- файлы.

Системы счисления:

- двоичная;
- восьмеричная;
- десятичная;
- шестнадцатеричная.

В программировании важны двоичное представление чисел, переполнение, точность вещественных чисел и кодировки символов.

## 8. Модульное программирование

Модульное программирование - подход, при котором программа разбивается на отдельные модули.

Модуль содержит:

- интерфейс;
- реализацию;
- данные;
- подпрограммы.

Преимущества:

- повторное использование;
- независимая разработка;
- упрощение тестирования;
- скрытие реализации;
- удобство сопровождения.

Многомодульная программа состоит из нескольких исходных файлов, которые компилируются отдельно и затем связываются компоновщиком.

## 12. Функции и передача данных

Функция в C имеет имя, тип результата, список параметров и тело.

```c
int square(int x) {
    return x * x;
}
```

Передача параметров в C выполняется по значению.

Чтобы функция изменила переменную вызывающего кода, используют указатель:

```c
void inc(int *x) {
    *x = *x + 1;
}
```

---

## 13. Указатели, массивы, строки

Указатель хранит адрес объекта.

```c
int x = 10;
int *p = &x;
```

Массив - последовательность элементов одного типа.

```c
int a[10];
```

Строка в C - массив символов, заканчивающийся нулевым символом.

```c
char s[] = "hello";
```

Работа со строками выполняется функциями из `string.h`.

---

## 14. Файлы в C

Файлы обрабатываются через указатель `FILE *`.

Пример:

```c
#include <stdio.h>

int main(void) {
    FILE *f = fopen("data.txt", "r");
    if (f == NULL) {
        return 1;
    }

    int x;
    fscanf(f, "%d", &x);
    fclose(f);
    return 0;
}
```

Основные функции:

- `fopen`;
- `fclose`;
- `fprintf`;
- `fscanf`;
- `fgets`;
- `fputs`;
- `fread`;
- `fwrite`.
