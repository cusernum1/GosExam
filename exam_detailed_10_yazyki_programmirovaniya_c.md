## 2. Алгоритмы

Алгоритм - точное предписание, задающее последовательность действий для решения класса задач.

Свойства:

- дискретность;
- определенность;
- конечность;
- результативность;
- массовость.

Способы записи:

- словесное описание;
- псевдокод;
- блок-схема;
- таблица;
- программа.

Базовые структуры:

- следование;
- ветвление;
- цикл.

---

## 3. Жизненный цикл программы

Жизненный цикл:

- требования;
- проектирование;
- кодирование;
- тестирование;
- внедрение;
- эксплуатация;
- сопровождение;
- развитие.

Спецификация отвечает на вопрос "что должна делать программа". Реализация отвечает на вопрос "как она это делает".

Верификация проверяет соответствие программы спецификации.

Тестирование обнаруживает ошибки на выбранных наборах данных, но не доказывает полное отсутствие ошибок.

## 4. Языки программирования

Машинный язык непосредственно исполняется процессором.

Алгоритмический язык или язык высокого уровня ближе к человеческому описанию алгоритма.

Стадии обработки исходного текста в C:

1. Препроцессор.
2. Компиляция.
3. Ассемблирование.
4. Компоновка.
5. Загрузка и выполнение.

Препроцессор обрабатывает `#include`, `#define` и условную компиляцию.

Данные - информация в форме, пригодной для обработки.

Типы данных в C:

- `char`;
- `int`;
- `float`;
- `double`;
- массивы;
- указатели;
- структуры;

Системы счисления:

## 6. Модульное программирование

Модульная программа состоит из нескольких логических частей.

В C модуль часто представлен парой файлов:

```text
module.h - интерфейс
module.c - реализация
```

Заголовочный файл содержит объявления функций, типов и констант. Файл реализации содержит определения функций.

Компиляция модулей может выполняться отдельно, а затем объектные файлы связываются компоновщиком.

## 8. Операторы и инструкции

Арифметические операторы:

```text
+ - * / %
```

Операторы отношения:

```text
< <= > >= == !=
```

Логические:

```text
&& || !
```

Условный оператор:

```c
if (x > 0) {
    printf("positive");
} else {
    printf("not positive");
}
```

Циклы:

```c
while (condition) {}
do {} while (condition);
for (int i = 0; i < n; ++i) {}
```

---

## 9. Функции, указатели, массивы, строки

Функция:

```c
int square(int x) {
    return x * x;
}
```

В C параметры передаются по значению. Для изменения переменной вызывающей функции передается указатель.

```c
void inc(int *x) {
    *x = *x + 1;
}
```

Массив:

```c
int a[10];
```

Строка:

```c
char s[] = "hello";
```

Строка C заканчивается нулевым символом.

Типичная ошибка: выйти за границы массива или забыть место для нулевого символа.

---

## 10. Файлы

Файл в C обрабатывается через `FILE *`.

```c
FILE *f = fopen("data.txt", "r");
if (f == NULL) {
    return 1;
}
fclose(f);
```

Режимы:

- `r` - чтение;
- `w` - запись с перезаписью;
- `a` - добавление;
- `rb`, `wb` - бинарные режимы.

## 12. Полный устный ответ

Решение задачи на ЭВМ проходит этапы постановки, формализации, выбора метода, алгоритмизации, программирования, тестирования и сопровождения. Алгоритм должен быть определенным, дискретным, конечным, результативным и массовым. Язык C является компилируемым языком высокого уровня с низкоуровневыми средствами работы с памятью. Он поддерживает функции, указатели, массивы, структуры, файлы и препроцессор. Модульное программирование в C реализуется через заголовочные файлы и файлы реализации.
