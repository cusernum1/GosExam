# ГЭ 6. Алгоритмы и структуры данных

Файл подготовлен как отдельный экзаменационный конспект по структурам данных, сортировкам, таблицам и графам.

---

## 1. Основные структуры данных

Структура данных - это способ организации данных в памяти, обеспечивающий эффективное выполнение операций.

При выборе структуры данных учитывают:

- какие операции нужны;
- как часто выполняется поиск;
- как часто выполняляется вставка;
- как часто выполняется удаление;
- нужен ли порядок элементов;
- важна ли экономия памяти;
- хранятся ли данные в оперативной или внешней памяти.

---

## 2. Массив

Массив - структура данных, хранящая элементы одного типа в последовательных ячейках памяти.

Свойства:

- доступ по индексу выполняется за постоянное время;
- размер часто фиксирован;
- вставка в середину требует сдвига элементов;
- удаление из середины также требует сдвига.

Оценки:

| Операция | Сложность |
|---|---|
| доступ по индексу | `O(1)` |
| поиск без сортировки | `O(n)` |
| вставка в конец динамического массива | амортизированно `O(1)` |
| вставка в середину | `O(n)` |

---

## 3. Строки

Строка - последовательность символов.

Основные операции:

- получение длины;
- доступ к символу;
- сравнение;
- конкатенация;
- поиск подстроки;
- выделение подстроки;
- замена;
- разбиение.

В C строка часто представляется массивом символов, оканчивающимся нулевым символом. В языках высокого уровня строка обычно является отдельным типом данных.

---

## 4. Стек

Стек - структура данных с принципом LIFO.

```text
last in, first out
```

Основные операции:

- `push` - добавить элемент;
- `pop` - удалить верхний элемент;
- `top` - посмотреть верхний элемент;
- `empty` - проверить пустоту.

Применения:

- вызовы функций;
- проверка скобочных последовательностей;
- обход графов в глубину;
- вычисление выражений;
- отмена операций.

---

## 5. Очередь

Очередь - структура данных с принципом FIFO.

```text
first in, first out
```

Основные операции:

- `enqueue` - добавить в конец;
- `dequeue` - удалить из начала;
- `front` - посмотреть первый элемент.

Применения:

- планирование процессов;
- буферы;
- обход графов в ширину;
- очереди сообщений.

---

## 6. Линейные списки

Линейный список - последовательность элементов, где каждый элемент связан со следующим.

Виды:

- односвязный список;
- двусвязный список;
- циклический список.

Односвязный список содержит данные и ссылку на следующий элемент.

Преимущества:

- быстрая вставка после известного элемента;
- динамический размер;
- не нужен непрерывный блок памяти.

Недостатки:

- нет быстрого доступа по индексу;
- дополнительная память на ссылки;
- поиск элемента требует последовательного прохода.

---

## 7. Списки общего вида

Список общего вида может содержать в качестве элементов не только атомарные значения, но и другие списки.

Такая структура используется для представления:

- вложенных выражений;
- деревьев;
- синтаксических структур;
- иерархических данных.

Пример:

```text
(a, (b, c), d)
```

---

## 8. Деревья

Дерево - иерархическая структура данных, состоящая из узлов и ребер.

Основные понятия:

- корень;
- родитель;
- потомок;
- лист;
- высота;
- глубина;
- поддерево.

Бинарное дерево - дерево, в котором каждый узел имеет не более двух потомков.

Бинарное дерево поиска:

```text
левое поддерево содержит меньшие ключи, правое - большие ключи.
```

Операции поиска, вставки и удаления в сбалансированном дереве выполняются за `O(log n)`.

---

## 9. Таблицы и операции над ними

Таблица - структура, хранящая записи по ключам.

Основные операции:

- поиск по ключу;
- вставка записи;
- удаление записи;
- изменение записи;
- обход записей.

Виды таблиц:

| Вид | Особенность |
|---|---|
| Неупорядоченная | элементы не отсортированы |
| Сортированная | элементы упорядочены по ключу |
| Древовидная | реализована деревом поиска |
| Hash-таблица | использует хеш-функцию |

Неупорядоченная таблица проста, но поиск обычно `O(n)`.

Сортированная таблица позволяет бинарный поиск за `O(log n)`, но вставка может требовать сдвига.

Древовидная таблица обеспечивает эффективные операции при сбалансированности.

Hash-таблица обеспечивает в среднем `O(1)` для поиска, вставки и удаления, но требует обработки коллизий.

---

## 10. Hash-таблицы

Hash-таблица использует хеш-функцию, которая преобразует ключ в индекс массива.

Проблема коллизий возникает, когда разные ключи получают один и тот же индекс.

Методы разрешения коллизий:

- цепочки;
- открытая адресация;
- линейное пробирование;
- квадратичное пробирование;
- двойное хеширование.

Хорошая хеш-функция должна равномерно распределять ключи.

---

## 11. Методы внутренней сортировки

Внутренняя сортировка выполняется в оперативной памяти.

Основные методы:

| Метод | Средняя сложность | Особенность |
|---|---|---|
| Пузырьковая | `O(n^2)` | простая, но медленная |
| Выбором | `O(n^2)` | мало обменов |
| Вставками | `O(n^2)` | хороша почти для отсортированных данных |
| Быстрая | `O(n log n)` в среднем | быстрая на практике |
| Слиянием | `O(n log n)` | устойчивая, требует память |
| Пирамидальная | `O(n log n)` | сортировка на куче |

Устойчивость сортировки означает, что равные элементы сохраняют исходный относительный порядок.

---

## 12. Методы внешней сортировки

Внешняя сортировка применяется, когда данные не помещаются в оперативную память.

Основная идея:

1. Разбить файл на части.
2. Отсортировать каждую часть в памяти.
3. Записать отсортированные серии на диск.
4. Выполнить многопутевое слияние.

Классический метод - внешняя сортировка слиянием.

---

## 13. Графы

Граф состоит из множества вершин и множества ребер.

Виды графов:

- ориентированные;
- неориентированные;
- взвешенные;
- невзвешенные;
- связные;
- несвязные.

Способы представления:

| Представление | Память | Когда удобно |
|---|---|---|
| Матрица смежности | `O(n^2)` | плотные графы |
| Списки смежности | `O(n+m)` | разреженные графы |
| Список ребер | `O(m)` | алгоритмы на ребрах |

Здесь `n` - число вершин, `m` - число ребер.

---

## 14. Алгоритмы на графах

Основные алгоритмы:

| Задача | Алгоритм |
|---|---|
| Обход в глубину | DFS |
| Обход в ширину | BFS |
| Кратчайший путь без весов | BFS |
| Кратчайшие пути с неотрицательными весами | Дейкстра |
| Кратчайшие пути с отрицательными ребрами | Беллман-Форд |
| Все пары кратчайших путей | Флойд-Уоршелл |
| Минимальное остовное дерево | Краскал, Прим |
| Топологическая сортировка | DFS или алгоритм Кана |
| Компоненты связности | DFS/BFS |

DFS использует стек или рекурсию.

BFS использует очередь.

Алгоритм Дейкстры не применяется при отрицательных весах ребер.
