# ГЭ 9. Основы программирования: подробный ответ

Расширенный конспект по базовым конструкциям программирования.

---

## 1. Циклические инструкции

Цикл нужен для многократного выполнения блока команд.

### while

Цикл `while` проверяет условие до входа в тело.

```pascal
while condition do
begin
  statements;
end;
```

Особенность: тело может не выполниться ни разу.

Используется, когда заранее неизвестно число повторений.

### repeat until

Цикл `repeat until` проверяет условие после выполнения тела.

```pascal
repeat
  statements;
until condition;
```

Особенность: тело выполняется хотя бы один раз.

### for

Цикл `for` используется, когда число повторений известно или легко задается счетчиком.

```pascal
for i := 1 to n do
  writeln(i);
```

Типичная ошибка: изменять счетчик `for` внутри цикла без необходимости.

## 2. Тип данных запись

Запись объединяет несколько полей разных типов.

Пример:

```pascal
type
  Student = record
    name: string;
    age: integer;
    average: real;
  end;
```

Записи используются, когда нужно хранить сведения об одной сущности.

Обращение к полю:

```pascal
s.name := 'Ivan';
s.age := 20;
```

Запись отличается от массива тем, что поля могут иметь разные типы и имена.

## 3. Строковый тип

Строка - последовательность символов.

Операции:

- длина;
- доступ к символу;
- конкатенация;
- копирование части строки;
- поиск;
- удаление;
- вставка;
- сравнение.

Пример:

```pascal
s := 'exam';
writeln(length(s));
writeln(s[1]);
```

Важно: в разных языках индексация строк может начинаться с 0 или с 1.

## 4. Файлы

Файл - именованная область внешней памяти.

Операции:

- связать файловую переменную с именем файла;
- открыть для чтения или записи;
- прочитать данные;
- записать данные;
- закрыть файл.

Пример:

```pascal
assign(f, 'input.txt');
reset(f);
readln(f, x);
close(f);
```

При записи:

```pascal
assign(f, 'output.txt');
rewrite(f);
writeln(f, x);
close(f);
```

Типичная ошибка: забыть закрыть файл или читать после конца файла.

## 5. Процедуры и функции

Процедура выполняет действия. Функция возвращает значение.

Функция:

```pascal
function Square(x: integer): integer;
begin
  Square := x * x;
end;
```

Процедура:

```pascal
procedure PrintValue(x: integer);
begin
  writeln(x);
end;
```

Передача параметров:

- по значению - передается копия;
- по ссылке - подпрограмма может изменить исходную переменную;
- через константный параметр - копирование избегается, изменение запрещено.

## 6. Модули

Модуль разделяет интерфейс и реализацию.

Интерфейс содержит то, что доступно другим частям программы.

Реализация содержит внутренний код.

Пример:

```pascal
unit MathUtils;

interface
function Square(x: integer): integer;

implementation
function Square(x: integer): integer;
begin
  Square := x * x;
end;

end.
```

Модули нужны для:

- повторного использования;
- декомпозиции программы;
- скрытия реализации;
- независимого тестирования.

## 7. Динамические структуры данных. Односвязный список

Динамические структуры создаются во время выполнения программы.

Односвязный список состоит из узлов:

```text
data + next
```

Операции:

- создать узел;
- вставить в начало;
- вставить после узла;
- удалить узел;
- найти элемент;
- пройти по списку;
- освободить память.

Преимущества:

- размер заранее не фиксируется;
- вставки и удаления не требуют сдвига элементов.

Недостатки:

- нет доступа по индексу за `O(1)`;
- нужно аккуратно работать с указателями;
- есть риск утечек памяти.

## 8. Полный устный ответ

Основы программирования включают управляющие конструкции, структурированные типы данных, строки, файлы, подпрограммы, модули и динамические структуры. Циклы `while`, `repeat until` и `for` различаются моментом проверки условия и областью применения. Запись объединяет поля разных типов. Строка хранит последовательность символов. Файлы обеспечивают долговременное хранение данных. Процедуры и функции позволяют выделять повторяющиеся действия. Модули делят программу на интерфейс и реализацию. Односвязный список является примером динамической структуры данных.
