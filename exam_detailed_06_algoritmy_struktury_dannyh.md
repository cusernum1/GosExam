# ГЭ 6. Алгоритмы и структуры данных: подробный ответ

Расширенный конспект по структурам данных, таблицам, сортировкам и графам.

---

## 1. Что такое структура данных

Структура данных - способ организации данных, выбранный с учетом операций, которые нужно выполнять.

Главный принцип:

```text
нет универсально лучшей структуры данных; выбор зависит от задачи.
```

Например, массив хорош для быстрого доступа по индексу, но неудобен для частых вставок в начало. Связный список удобен для вставок, но не дает быстрого доступа к произвольному элементу.

---

## 2. Массив

Массив хранит элементы одного типа в последовательной области памяти.

Преимущества:

- быстрый доступ по индексу;
- компактное хранение;
- хорошая локальность памяти.

Недостатки:

- фиксированный размер у статического массива;
- дорогие вставки и удаления в середине;
- требуется непрерывная память.

Оценки:

| Операция | Сложность |
|---|---|
| Доступ по индексу | `O(1)` |
| Поиск без упорядочения | `O(n)` |
| Вставка в середину | `O(n)` |
| Удаление из середины | `O(n)` |

---

## 3. Строки

Строка - последовательность символов. В C строка завершается нулевым символом. В более высокоуровневых языках строка обычно является объектом со своей длиной и методами.

Операции:

- получение длины;
- сравнение;
- конкатенация;
- поиск подстроки;
- выделение подстроки;
- замена;
- разбиение;
- преобразование регистра.

Типичные алгоритмические задачи:

- поиск образца;
- проверка палиндрома;
- сравнение строк;
- хеширование строк;
- префикс-функция и Z-функция.

---

## 4. Стек

Стек работает по принципу LIFO.

```text
последний пришел - первый вышел
```

Операции:

- `push`;
- `pop`;
- `top`;
- `empty`.

Применения:

- стек вызовов функций;
- проверка скобок;
- вычисление выражений;
- обход графа в глубину;
- откат действий.

Типичная ошибка: извлекать элемент из пустого стека. Для корректной работы нужно проверять предусловие `not empty`.

---

## 5. Очередь

Очередь работает по принципу FIFO.

```text
первый пришел - первый вышел
```

Операции:

- добавление в конец;
- удаление из начала;
- просмотр первого элемента.

Применения:

- BFS;
- очереди задач;
- буферы;
- обработка сообщений.

Разновидности:

- обычная очередь;
- двусторонняя очередь;
- приоритетная очередь;
- циклическая очередь.

---

## 6. Линейные списки

Связный список состоит из узлов. Узел содержит данные и ссылку на следующий узел.

Односвязный список:

```text
data + next
```

Двусвязный список:

```text
prev + data + next
```

Преимущества:

- динамический размер;
- быстрая вставка после известного узла;
- не нужен непрерывный блок памяти.

Недостатки:

- поиск по индексу `O(n)`;
- больше памяти из-за ссылок;
- хуже локальность памяти.

---

## 7. Деревья

Дерево - иерархическая структура без циклов.

Основные понятия:

- корень;
- родитель;
- потомок;
- лист;
- глубина;
- высота;
- поддерево.

Бинарное дерево поиска поддерживает порядок:

```text
левые ключи меньше узла, правые больше узла.
```

Если дерево сбалансировано, операции поиска, вставки и удаления выполняются за `O(log n)`.

Если дерево вырождено в цепочку, операции становятся `O(n)`.

---

## 8. Таблицы

Таблица хранит записи, обычно доступные по ключу.

Варианты реализации:

| Таблица | Поиск | Особенность |
|---|---|---|
| Неупорядоченная | `O(n)` | простая вставка |
| Сортированная | `O(log n)` для поиска | вставка может быть `O(n)` |
| Древовидная | `O(log n)` при балансе | сохраняет порядок |
| Hash | в среднем `O(1)` | порядок не сохраняется |

Hash-таблица требует хеш-функцию и механизм разрешения коллизий.

Методы коллизий:

- цепочки;
- открытая адресация;
- линейное пробирование;
- квадратичное пробирование;
- двойное хеширование.

---

## 9. Сортировка

Внутренняя сортировка выполняется в оперативной памяти.

Основные методы:

| Метод | Средняя сложность | Уточнение |
|---|---|---|
| Пузырек | `O(n^2)` | учебный простой метод |
| Выбор | `O(n^2)` | мало обменов |
| Вставки | `O(n^2)` | хорош для почти отсортированных данных |
| Быстрая | `O(n log n)` в среднем | худший случай `O(n^2)` |
| Слиянием | `O(n log n)` | устойчива, требует память |
| Пирамидальная | `O(n log n)` | использует кучу |

Устойчивая сортировка сохраняет порядок равных элементов.

Внешняя сортировка применяется, когда данные не помещаются в оперативную память. Обычно используется сортировка слиянием: данные разбивают на серии, сортируют серии, затем сливают.

---

## 10. Графы

Граф состоит из вершин и ребер.

Виды:

- ориентированный;
- неориентированный;
- взвешенный;
- невзвешенный;
- связный;
- несвязный.

Представления:

| Представление | Память | Когда удобно |
|---|---|---|
| Матрица смежности | `O(n^2)` | плотные графы |
| Списки смежности | `O(n+m)` | разреженные графы |
| Список ребер | `O(m)` | алгоритмы на ребрах |

---

## 11. Алгоритмы на графах

DFS - обход в глубину. Использует стек или рекурсию. Применяется для поиска компонент связности, топологической сортировки, обнаружения циклов.

BFS - обход в ширину. Использует очередь. Находит кратчайшие пути в невзвешенном графе.

Алгоритм Дейкстры - кратчайшие пути от одной вершины при неотрицательных весах.

Алгоритм Беллмана-Форда допускает отрицательные ребра и может обнаруживать отрицательные циклы.

Алгоритм Флойда-Уоршелла находит кратчайшие пути между всеми парами вершин.

Алгоритмы Краскала и Прима строят минимальное остовное дерево.

---

## 12. Полный устный ответ

Структуры данных выбираются в зависимости от операций. Массив обеспечивает быстрый доступ по индексу, стек реализует LIFO, очередь реализует FIFO, связный список удобен для динамических вставок, деревья задают иерархию и эффективный поиск при балансировке, таблицы обеспечивают доступ по ключу, hash-таблицы дают среднее время `O(1)`.

Сортировки делятся на внутренние и внешние. Внутренние выполняются в памяти, внешние применяются для больших файлов. Графы представляются матрицей смежности, списками смежности или списком ребер. Основные алгоритмы на графах: DFS, BFS, Дейкстра, Беллман-Форд, Флойд-Уоршелл, Краскал и Прим.
