# ГЭ 9. Основы программирования

## 1. Циклические инструкции

Цикл - управляющая конструкция, позволяющая многократно выполнять блок команд.

Основные виды:

- `while`;
- `repeat until`;
- `for`.

### Цикл while

Цикл `while` проверяет условие до выполнения тела.

```text
while условие do
    тело цикла
```

Если условие изначально ложно, тело цикла не выполнится ни разу.

Пример:

```pascal
i := 1;
while i <= 10 do
begin
  writeln(i);
  i := i + 1;
end;
```

### Цикл repeat until

Цикл `repeat until` проверяет условие после выполнения тела.

```text
repeat
    тело цикла
until условие;
```

Тело выполняется хотя бы один раз.

Пример:

```pascal
repeat
  readln(x);
until x > 0;
```

### Цикл for

Цикл `for` используется, когда известно число повторений.

```pascal
for i := 1 to 10 do
  writeln(i);
```

## 2. Тип данных запись

Запись - структурированный тип данных, объединяющий несколько полей, возможно разных типов.

Пример:

```pascal
type
  Student = record
    name: string;
    age: integer;
    grade: real;
  end;
```

Использование:

```pascal
var s: Student;
begin
  s.name := 'Ivan';
  s.age := 20;
  s.grade := 4.5;
end;
```

Записи удобны для описания объектов предметной области.

---

## 3. Строковый тип данных

Строка - последовательность символов.

Основные операции:

- определение длины;
- доступ к символу;
- конкатенация;
- копирование подстроки;
- поиск подстроки;
- удаление символов;
- вставка;
- сравнение.

Пример:

```pascal
var s: string;
begin
  s := 'Hello';
  writeln(length(s));
  writeln(s[1]);
end;
```

---

## 4. Файлы и операции над файлами

Файл - именованная область внешней памяти, предназначенная для хранения данных.

Основные операции:

- открытие;
- чтение;
- запись;
- добавление;
- закрытие;
- проверка конца файла.

Пример текстового файла:

```pascal
var f: text;
    x: integer;
begin
  assign(f, 'input.txt');
  reset(f);
  readln(f, x);
  close(f);
end;
```

При работе с файлами важно закрывать файл после завершения операций.

## 5. Процедуры и функции

Подпрограмма - именованный фрагмент программы, который можно вызывать из разных мест.

Процедура выполняет действия.

Функция возвращает значение.

Пример функции:

```pascal
function Square(x: integer): integer;
begin
  Square := x * x;
end;
```

Способы передачи параметров:

- по значению;
- по ссылке;
- через константный параметр.

Передача по значению означает, что подпрограмма получает копию значения.

Передача по ссылке позволяет изменить исходную переменную.

## 6. Модули

Модуль - отдельная программная единица, содержащая объявления типов, переменных, процедур и функций.

Назначение модулей:

- разбиение программы на части;
- повторное использование кода;
- скрытие реализации;
- упрощение сопровождения.

Типичная структура модуля:

```pascal
unit MyModule;

interface

procedure PrintHello;

implementation

procedure PrintHello;
begin
  writeln('Hello');
end;

end.
```

Раздел `interface` содержит то, что доступно другим модулям.

Раздел `implementation` содержит реализацию.

## 7. Динамические структуры данных. Односвязный список

Динамические структуры данных создаются во время выполнения программы и могут изменять размер.

Односвязный список состоит из узлов. Каждый узел содержит данные и ссылку на следующий узел.

Схема узла:

```text
data + next
```

Основные операции:

- создание узла;
- вставка в начало;
- вставка после элемента;
- удаление элемента;
- поиск;
- обход списка;
- освобождение памяти.

Преимущества:

- размер изменяется динамически;
- вставка и удаление не требуют сдвига элементов.

Недостатки:

- нет быстрого доступа по индексу;
- нужна дополнительная память на ссылки;
- сложнее управление памятью.
